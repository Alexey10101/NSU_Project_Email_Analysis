# Анализ электронных писем

Программа извлекает признаки ИИ-правок из писем в формате EML.

- `analysis` — парсер и анализаторы текста, HTML и признаков письма.
- `training` — подготовка таблицы, обучение CatBoost и отчёты.
- `scripts` — загрузка датасетов и подготовка пар HTML-писем.
- `tests` — проверка кода, сравнение пары писем и оценка нейросетевого блока.
- `models` — сохранённые модели и калибровки.
- `datasets` — локальные датасеты и сведения об источниках.
- `info` — план и материалы проекта.

## Последнее обновление

Добавление экспериментального нейросетевого анализа по абзацам. [Исходный эксперимент](https://github.com/Alexey10101/NSU_Project_Email_Analysis/tree/385a99e551d35f1f245822d9903045da39e01482) подготовил tmshaba. DistilBERT предлагает замены слов, Qwen измеряет изменение предсказуемости текста. Анализатор возвращает числовой балл и фрагмент с максимальным изменением. CatBoost по-прежнему оценивает письмо по текстовым признакам PASTED.

```text
python -m pip install -r requirements.txt
python -m pip install -r analysis/requirements-neural.txt
python analysis/neural_analyze.py письмо.eml --output результат.json
python tests/evaluate_neural.py --output neural_metrics.json
```

Нейросетевые зависимости нужны только для последних двух команд. При первом запуске загружаются веса DistilBERT и Qwen. Письма обрабатываются на компьютере. Калибровка и порог в отчёте рассчитываются на validation, итоговые метрики — на test. В отчёте указано, сколько писем удалось оценить.

Подготовка данных и обучение CatBoost описаны в [инструкции](training/README.md).
