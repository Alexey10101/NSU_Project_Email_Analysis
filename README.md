# Анализ писем

- `analysis` — парсер, текстовый и HTML-анализаторы.
- `training` — сбор признаков и обучение CatBoost, журналы и отчёты.
- `scripts` — загрузчик датасетов.
- `tests` — запуск сравнения случайной пары писем.
- `models` — сохранённые модели и калибровки.
- `datasets` — данные и сведения об источниках.
- `info` — план и материалы проекта.

Запускай `tests/test.py` для сравнения пары. Пути вычисляются относительно файлов проекта и не зависят от рабочей папки IDE.

`scripts/download_datasets.py` загружает PASTED и SpamAssassin целиком, а GenImage — небольшой выборкой: 50 реальных и 50 ИИ-изображений в каждом из train и validation. Объём выборки меняется через `--image-limit`. Полные архивы включаются только параметром `--full-genimage` и сохраняются отдельно в `datasets/GenImage_full`.

Выборка изображений получена из Tiny-GenImage через Dataset Viewer. Это данные для разработки; перед полноценным обучением нужно проверить преобразования изображений, дубликаты и выделить независимый test. Изображения не являются вложениями реальных писем.

PASTED содержит текстовые пары с искусственными заголовками. SpamAssassin содержит реальные письма с разметкой spam/ham, которая не означает происхождение ИИ. Для HTML-классификатора ещё нужны парные размеченные версии писем с HTML.

Текстовая модель сохранена в `models/text_classifier.json`. Чтобы обучить её заново, запусти `analysis/text_analyze.py`. Разбиения нового PASTED сохраняются при обучении.

Для CatBoost сначала запусти `training/build_table.py`, затем `training/train_boosting.py`. Таблица и отчёт сохраняются в `training`, модель — в `models`. Бустинг использует исходные train/test и текстовые признаки без готовой оценки логистической модели.

Базовые зависимости перечислены в `requirements.txt`, дополнительные зависимости CatBoost — в `training/requirements.txt`. Датасеты, виртуальное окружение и журналы обучения не хранятся в репозитории. После скачивания проекта запусти `scripts/download_datasets.py`, чтобы создать папку с данными.
